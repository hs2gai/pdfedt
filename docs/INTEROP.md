# ビューア互換性の確認手順と結果

本アプリで書き出した PDF が、主要なビューアで同じように見える・印刷できることを確認する。

## 手順

1. `pnpm test:e2e` を実行すると、Playwright のダウンロード先（`test-results/` 配下）に各保存方式の PDF が残る。または開発中に `window.__pdf.saveTo('incremental', 'name.pdf')`（DEV / E2E ビルドのみ）で `_spike-out/` に保存する
2. 以下の各ビューアで開き、チェック項目を確認する

| チェック項目 | 期待 |
|---|---|
| 日本語テキスト注釈が表示される | 文字化け・豆腐・欠落なし |
| 印刷プレビューに注釈が出る | 全注釈が印刷対象（`/F` Print） |
| 注釈を選択・移動・削除できる | Acrobat では「スタンプ」として扱われる（テキスト再編集は不可） |
| 付箋のコメントが読める | ポップアップに本文が出る |
| ハイライト・図形・手書きの色と太さ | エディタ上と同じ |
| 「注釈付きで保存」した署名付き文書 | 署名が有効なまま（DocMDP 3 の場合） |

## 既知の注意点

- テキスト注釈は `/Subtype /Stamp` として書かれる（`@embedpdf/pdfium` 2.15.1 の FreeText 外観生成の不具合を避けるため）。Acrobat で文字として再編集することはできないが、本アプリでは「編集」から書き換えられる
- 「注釈付きで保存」は、変更のないオブジェクトを増分から落としてスリム化している。描画中に遅延読み込みされた未変更オブジェクトが少量含まれることはある（正しさには影響しない）
