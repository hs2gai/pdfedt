# pdfedt

[English](README.md) | 日本語

PDFをブラウザの中だけでローカルで編集して保存するツールです。日本でよく見られるPDF文書（申込書、申請書、稟議書等）をAcrobatなどのツール無しで編集したいユーザーを主な対象にしています。PDFの完全な仕様をカバーする予定はありませんが、なるべく元の文書を壊さずに注釈を追加したり、簡易的な編集をしたものを保存できるようにすることを目的としています。

- サーバーにファイルを送信しません（CSPでブラウザからの外部通信を遮断）
- 元のPDFを書き換えずに注釈を追記保存できます
- 日本語のテキスト注釈を埋め込みフォント付きで表示します
- フォントを埋め込んでいない和文PDFも同梱フォントで表示します

## 使い方

1. 「開く」からPDFを選ぶか、画面にドラッグ＆ドロップ
2. ツールバーからツールを選んで書き込む
   - テキスト / スタンプ（承認・済・日付印・認印など） / 画像 / 付箋 / ハイライト / 下線 / 取消線 / 手書き / 四角 / 楕円 / 直線 / 矢印
3. 「保存 ▾」から書き出す
   - **注釈付きで保存** … 元のPDFはそのまま、注釈だけを追記（既定）。ファイル名は`元の名前_a.pdf`
   - **新ファイルで保存** … 現在の状態からPDFを新しく生成する（消した注釈は残らない）。`_n.pdf`
   - **確定して書き出し** … 内容を焼き込む（注釈の編集はできなくなる）。`_f.pdf`

**本文編集モード**（ツールバー右端の鉛筆）: 「本文」ツールで元の内容の文字・図形・画像を移動・削除・置換できます。モード中も注釈はそのまま扱えます（注釈をクリックすると選択ツール、本文をクリックすると「本文」ツールに自動で切り替わります）。元のPDFを書き換えるため、保存は別名になります。電子署名で変更が禁止された文書では使えません。「PCのフォントを使う」オプション（後述）を使わないときは、置換した文字は同梱フォント（ゴシック / 明朝）で埋め込みます。

**PCのフォントを使う**（設定）: オンにすると、元の文書と同じ書体（MS 明朝・游ゴシックなど）がPCにあれば、フォント非埋め込みの文書の表示と、本文編集で置換した文字の埋め込みにその書体を使います。テキスト注釈やスタンプの書体にもPCの和文フォント（IPA・游・BIZ UDなど）を選べます。ブラウザからPC上のフォントを直接読み、外部には送信しません。ライセンスで埋め込みが禁止されたフォントは埋め込みに使いません。

**ページの操作**（左のサムネイル）: クリックで選んで`Delete`キーで削除、ドラッグで並べ替え、PDFファイルをサムネイルの上に落とすとその位置にページを追加できます。ページ構成を変えた文書は、本文編集と同じく「新ファイルで保存」になります。

**パスワード付きPDF**: 開くときにパスワードを入力します（パスワードは保存・送信しません）。保存しても同じパスワードが付いたままになります。「保存 ▾」→「パスワードを付けて保存…」で、開くときにパスワードが必要なPDF（AES-256）を新しく作れます（「新ファイルで保存」または「確定して書き出し」の形式）。ただしパスワード機能については無保証です。

タッチ操作: 一本指はツールの操作（文字・注釈の選択、スタンプの配置）、**二本指でスクロール、ピンチで拡大縮小**。Ctrl + マウスホイールでも拡大縮小できます。

キーボード: `Delete` 削除 / `Ctrl+Z` 元に戻す / `Ctrl+Y` やり直す / `Esc` 選択ツールへ / テキスト入力中 `Ctrl+Enter` 確定

## 言語

UIは日本語（既定）と英語を切り替えられます（設定 ⚙ →「言語 / Language」）。文字列は`src/i18n/ja.json`と`src/i18n/en.json`にあり、言語を足すときはJSONを1つ追加して`src/i18n/index.ts`の`LOCALES`に登録します。

## 対応ブラウザ

| ブラウザ | 状況 |
|---|---|
| Chrome / Edge（最新版、PC） | 対応。自動テストはChromiumで実施 |
| Firefox / Safari（最新版、PC） | 動作する見込みだが未検証 |
| スマートフォン・タブレット | タッチ操作（二本指スクロール・ピンチ）に対応しているが、テストは不十分 |

Chrome / Edge以外との違い:

- **「PCのフォントを使う」機能はChrome / Edge（Chromium系）のみ**です。PCのフォントを読むLocal Font Access APIをFirefox・Safariが実装していないためで、非対応ブラウザでは設定項目自体が表示されず、置換は同梱フォントで行われます。
- 保存ダイアログ（保存先とファイル名を選ぶ）はFile System Access APIを使うためChromium系のみです。ほかのブラウザでは常にダウンロードとして保存されます。

## 対応PDF

- PDF 1.xとPDF 2.0を開けます。パスワード付きPDFはパスワードを入力して開きます。
- フォーム: AcroFormの入力欄に記入できます。**XFAフォームには対応していません**。
- 保存したファイルの版:
  - 注釈付きで保存: 元のバイト列の後ろに追記するため、元の版（と電子署名）がそのまま残ります。
  - 新ファイル / 確定: ファイル全体を書き直し、元がPDF 2.0でもPDF 1.7として出力します。

## Chrome拡張

Chromeの内蔵PDFビューワの代わりにpdfedtを使う拡張です。ブラウザでPDFを開くと（リンク・アドレスバー・ローカルファイル）、そのタブがpdfedtに切り替わります。ストアには出していませんが、ビルド済みの拡張をリポジトリの`dist-ext/`に同梱しています。

1. リポジトリを入手する（`git clone`、またはGitHubの「Download ZIP」で取得して展開）
2. `chrome://extensions`を開き、右上の「デベロッパーモード」をオン
3. 「パッケージ化されていない拡張機能を読み込む」で`dist-ext/`フォルダを選ぶ
4. ローカルのPDF（`file://`、ダウンロード履歴からのオープンを含む）も開きたければ、拡張の「詳細」→「ファイルのURLへのアクセスを許可する」がオンになっていることを確認（未パッケージの拡張は通常オン）

拡張が取りに行くのは「ユーザーが開こうとしたPDFのURL」だけで、それ以外の通信はWeb版と同じくありません。自動で切り替えたくないときは、ツールバーのアイコンを右クリック →「PDFを自動でpdfedtで開く」のチェックを外すと、アイコンのクリックとPDFリンクの右クリックメニューからだけ開くようになります。

自分でビルドしたい場合は、次を実行して同じように`dist-ext/`を読み込みます。ビルドし直したとき（リポジトリを更新したときも）は`chrome://extensions`の更新ボタンで反映されます。

```bash
pnpm install
pnpm build:ext    # dist-ext/に拡張一式を出力
```

## 開発

```bash
pnpm install
pnpm dev          # http://localhost:5173
pnpm build        # dist/に静的ファイルを出力
pnpm build:ext    # dist-ext/にChrome拡張を出力（tests/e2e/extension.spec.tsが使う）
pnpm preview      # 本番相当（厳格なCSP付き）で確認
pnpm test         # Vitest（ロジックのユニットテスト）
pnpm test:e2e     # Playwright（本番ビルドに対して実行）
python samples/make_samples.py   # 検証用サンプルPDFの再生成（reportlab / PyMuPDF）
```
